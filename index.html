How A* Works

A* Evaluation Function
f(n) = g(n) + h(n)
  • g(n): Cost from Start to current cell
  • h(n): Estimated cost from current cell to Goal
  • f(n): Total estimated cost
Heuristic: Manhattan Distance
h(n) = |x1 - x2| + |y1 - y2|

Measures orthogonal grid distance between cell (x1, y1) and destination (x2, y2).

Movement Allowed
↑ Up ↓ Down ← Left → Right
❌ No diagonal movement

Algorithm Complexity

Time Complexity: O((V + E) log V)

Where V is total grid cells (225 vertices) and E is valid transitions (edges). Selecting the node with minimum f(n) from Open List takes logarithmic time using a Priority Queue / Min-Heap.

Space Complexity: O(V)

Stores nodes in Open List, Closed Set, and parent pointers to reconstruct the optimal shortest path.
